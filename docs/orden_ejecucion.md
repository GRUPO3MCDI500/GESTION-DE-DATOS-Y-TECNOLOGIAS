# Orden de ejecución

1. Instalar Java 17 y PySpark 4.0.1.
2. Importar librerías y configurar variables.
3. Crear SparkSession y SparkContext.
4. Localizar o cargar los seis archivos.
5. Crear RDD deportista con 6 particiones.
6. Crear deportista2 y unirlos en deportistaTotal.
7. Convertir deportistaTotal a DataFrame.
8. Ejecutar transformaciones de RDD.
9. Crear Evento, Resultado, Equipos y Juego.
10. Persistir, cachear e integrar las cinco tablas.
11. Reparticionar el DataFrame integrado a 5 particiones.
12. Inspeccionar el DataFrame.
13. Crear IMC y Descripción_sexo.
14. Registrar la vista Spark SQL.
15. Ejecutar las cuatro agregaciones.
16. Revisar el plan de ejecución.
17. Ejecutar validaciones finales.
18. Liberar recursos de manera opcional.
